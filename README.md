# BudgetAM 💰

BudgetAM is a budgeting and expense tracking application designed to help young Nigerians manage spending, prioritize essential expenses, and avoid running out of money before month-end.

---

## 🌐 Live Demo

https://budgetam-naija-money.lovable.app

---

## ✨ Features

- User onboarding and authentication
- Income setup
- Expense tracking
- Daily allowance calculation
- Overspending alerts
- Survival forecast
- Priority-based budgeting

---

## 🛠️ Tech Stack

- Lovable

---

## 📱 Usage

To use BudgetAM:

1. Open the app  
2. Create an account and verify your email  
3. Complete onboarding setup  
4. Start tracking your income and expenses immediately  

That’s it — BudgetAM is ready to use right after signup.
